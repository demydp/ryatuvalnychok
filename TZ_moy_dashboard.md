# ТЕХ-ЗАДАНИЕ: Reels + Ads Analytics (моя версия)

**Цель:** чистая, полностью рабочая версия дашборда аналитики Instagram Reels + рекламы, собранная с нуля под меня, готовая к продаже другим людям. Никакого чужого кода — всё оригинальное.

**Дизайн:** белый фон, чёрный текст, акцент **#bd94eb** (фиолетовый). Чисто, современно, без визуального мусора. Montserrat или системный шрифт.

**Стек:** Python + Flask (бэкенд), одностраничный дашборд (HTML/CSS/JS, графики — Chart.js). Запуск двойным кликом (start.bat / позже .exe), сервер в фоне.

---

## Ключевой принцип для продажи

Программа НЕ должна хранить мои ключи в коде. Нужен экран **«Настройки»** внутри дашборда, где ЛЮБОЙ пользователь вставляет свои данные:

- Instagram Access Token (долгоживущий)
- Anthropic API Key (для генератора и анализа)
- Кнопка «Проверить подключение» → показывает имя аккаунта, если всё ок
- IG User ID определяется автоматически из токена (не вводить руками)
- Всё сохраняется локально в config.json (не в коде)

Рядом — короткая подсказка «как получить токен» со ссылками. Так программу можно отдавать людям: поставил → вставил свои ключи → работает.

## Честные ограничения API (заложить в код, показывать понятно)

1. Часть инсайтов Instagram отдаёт только для аккаунтов **от 1000 подписчиков**. Если метрики нет — показывать «нет данных (аккаунт < 1000 подписчиков или пост до перехода в бизнес)», а не ноль и не ошибку.
2. Посты, опубликованные **до перехода в бизнес-аккаунт**, не имеют инсайтов (subcode 2108006) — помечать «инсайты недоступны», не ронять синк.
3. Метрики зависят от типа медиа (REELS/VIDEO ≠ IMAGE ≠ CAROUSEL) — запрашивать только поддерживаемые.
4. **Skip Rate (3с)** и продвинутые метрики — из обновлённого Insights API (дек. 2025), могут требовать доп. доступа. Если недоступны — показывать «нет данных», не падать.
5. Точной посекундной кривой удержания в API нет — используем skip rate + средний досмотр как замену.
6. Цифры должны совпадать с тем, что видно в приложении Instagram (рекламные показы органику не искажают — это разные разрезы).

## Функции (вкладки)

### 1. Настройки
Ввод токенов/ключей, проверка подключения, автоопределение IG User ID, подсказки. (см. выше)

### 2. Обзор / Метрики рилсов
Точные метрики по каждому посту, строго по документации Meta:
- reach (охват), views/plays (просмотры), likes, comments, saved, shares, total_interactions
- engagement rate = total_interactions / reach
- saves rate, shares rate
Таблица со всеми постами + сортировки (по охвату, ER, сохранениям, репостам, дате). Топ-карточки. Графики (Chart.js). Пагинация — тянуть ВСЕ посты (paging.next), лимит MAX_MEDIA в настройках.

### 3. Что заходит (анализ + рекомендации)
Автоматический разбор по цифрам:
- Лучшие/худшие по ER, по сохранениям/охват, по репостам
- Анализ по времени/дню публикации (когда заходит)
- Анализ по длине видео
- **Результат видео**: сколько дал подписок, лайков, взаимодействий
- Конкретные текстовые рекомендации: «твои топ-рилсы объединяет X → делай больше такого», «посты в это время заходят хуже → сдвинь»

### 4. Хук-анализ
- **Skip Rate (3с)** — % ушедших в первые 3 секунды (где API отдаёт)
- Средний досмотр (где доступен)
- Связка с транскриптом: показать первую фразу (хук) рилса рядом со skip rate → видно, какие заходы цепляют, а какие сливают
- Вывод: «хуки с вопросом/болью держат лучше» и т.п.

### 5. Транскрипция (Whisper)
- Локальная расшифровка речи рилсов (openai-whisper + ffmpeg, офлайн, бесплатно)
- Кэшировать результат (не расшифровывать повторно)
- Показывать текст рядом с метриками поста
- Флаг: тяжёлая, первый запуск качает модель — вынести в отдельную кнопку, не в авто-синк

### 6. Генератор скриптов
- Пишет сценарии рилсов в МОЁМ стиле через Claude (Anthropic API из настроек)
- Берёт за основу мои топ-рилсы + их транскрипты (учится на том, что зашло)
- Ввод темы → выдаёт скрипт (хук + тело + CTA)
- Экономный режим: дать выбор модели (подешевле — чтобы экономить баланс покупателя)

### 7. Реклама (отдельный модуль, Marketing API)
- Отдельный доступ: рекламный кабинет + ads_read
- Основные метрики: расход, показы, CPM, клики, CTR, CPC, результаты (лиды/конверсии), CPL/CPA, ROAS/ДРР
- Разбор кампаний/групп/объявлений: что дешевле, что дороже
- Рекомендации по цифрам (как в моих материалах по таргету)
- Заложить как отдельную вкладку с собственным подключением (свой токен ad account)
