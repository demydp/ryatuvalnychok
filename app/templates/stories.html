Сторіс

Натисни «Синхронізувати», щоб завантажити активні сторіс з Instagram.

Instagram Graph API віддає список сторіс лише поки вони живі (~24 год), а їхні інсайти — трохи довше. Тому дані накопичуються в історію при кожному синку (ручному або фоновому — раз на кілька годин) і не зникають після того, як сама сторіс зникне з Instagram.

Охоплення акаунта: підписники / не підписники

Розбивку «підписники / не підписники» Instagram API віддає ЛИШЕ на рівні всього акаунта — по кожній окремій сторіс чи посту такого розподілу API чесно не надає (перевірено: Graph API прямо відхиляє такий запит).
