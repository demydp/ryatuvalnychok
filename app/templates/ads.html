Мои KPI (цели по цели кампании)

Задайте свои целевые цифры отдельно для каждой цели кампании — дальше факт по каждой кампании/группе будет сравниваться с ними и подсвечиваться как «успех / норма / провал». Поля необязательны — заполните только то, что применимо к вашей цели (например, ROAS не имеет смысла для «Узнаваемости»).

Ориентиры (очень грубо, зависит от ниши/рынка — не норматив):

    Сырые цифры (для сверки с Ads Manager)

    Бюджет/ставка берутся с ноды кампании/группы (переведены из минорных единиц валюты кабинета). Остальные цифры — напрямую из Insights API за выбранный период, без округлений сверх того, что отдаёт Meta. Если что-то разойдётся с Ads Manager — это сигнал поправить конвертацию, а не список полей.
